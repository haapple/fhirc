全域伺服器設定 (FHIR Base URL)

所有資源 (Organization、Patient、Observation) 均依此端點進行標準 RESTful API 請求

醫護端應用：病患歷史量測查詢與管理 (Observation Viewer & CRUD) 準備就緒
